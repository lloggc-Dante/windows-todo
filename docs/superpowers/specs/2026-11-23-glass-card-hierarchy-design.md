# 玻璃卡片式 UI 视觉层级设计

## 目标与原因

采用用户选定的“玻璃卡片式分层”方向，让主窗口与桌面贴片具有更明确的面板层级、选中状态和操作主次，同时保持浅色、清透、轻量的苹果式玻璃观感。

## 范围

- 主窗口保留现有三栏结构与全部功能。
- 清单导航、任务工作区、任务详情成为三个独立但协调的玻璃面板。
- 快速添加区作为任务工作区的主要操作，任务标题和当前选中项拥有更高视觉权重。
- 任务使用轻量独立卡片；默认卡片保持安静，悬停与选中时才增强边缘、亮度和浮起感。
- 详情字段按清单、标题、备注、时间及完成历史分组，减少所有控件同样突出造成的噪声。
- 桌面贴片同步使用玻璃任务卡片和添加控件，但不改变八行上限、滚动、拖动、缩放和窗口透明行为。
- 保留现有交互动效，并让新增视觉状态遵循减少动态效果设置。

## 非目标

- 不新增、删除或调整任务功能。
- 不改变数据结构、快捷键、窗口层级与托盘行为。
- 不恢复拖动贴片时的背景高斯模糊。
- 不引入新的 UI 框架、图标库或依赖。

## 已考虑方案

- 内容优先的精细分层：最克制，但玻璃空间感较弱。
- 玻璃卡片式分层：层次和材质最明确，已选择；实现时需控制边框、阴影和卡片数量，避免界面显得繁复。
- 极简留白：最安静，但不符合本次希望强化玻璃层次的视觉方向。

## 实现约束

- 在现有 Vue 组件与 CSS 基础上调整，沿用 `apple-glass.css` 的材质变量和 `motion.css` 的动效约定。
- 主窗口通过面板留白、透明度和局部高光分层，而不是依赖大面积高饱和底色。
- 贴片保持无背景模糊，玻璃感由轻薄渐变、亮边和局部阴影承担。
- 小宽度下继续隐藏详情栏，保证任务区可用；既有测试选择器和交互区域保持有效。

## 验证

- 在真实应用窗口中检查默认、悬停、选中、输入聚焦及空状态。
- 检查主窗口窄宽度与贴片八行滚动状态。
- 运行类型检查、全部单元测试和端到端测试，并重新生成 Windows 安装包。
